PintoTV

Einen Fernseher aus der Ferne einrichten. Den Gerätecode zeigt PintoTV auf dem Fernseher an (Playlists-Bildschirm, oben).

So funktioniert's

1. PintoTV auf dem Fernseher installieren
  1. Fire TV: Zuerst die kostenlose App Downloader aus dem Amazon App Store installieren. Dann Einstellungen → Mein Fire TV → Entwickleroptionen → Unbekannte Apps installieren → Downloader einschalten. (Fehlen die Entwickleroptionen: Mein Fire TV → Info → 7× auf den Gerätenamen drücken.)
  2. NVIDIA Shield / Android TV: Die App Downloader aus dem Play Store installieren. Dann Einstellungen → Geräteeinstellungen → Sicherheit & Einschränkungen → Unbekannte Quellen → Downloader einschalten.
  3. In Downloader diese Adresse eingeben und die App installieren:
    github.com/jorgepnt-design/iptv/raw/main/pintotv.apk
  4. PintoTV öffnen. Spätere Updates kommen über Menü → Nach Updates suchen.
2. Gerätecode am Fernseher ablesen
  1. In PintoTV den Bildschirm Playlists öffnen (beim ersten Start erscheint er von selbst, sonst: Menü → Playlists).
  2. Ganz oben steht der Gerätecode, z. B. PT-7K3F-92XA.
  3. Größer mit QR-Code: ⇄ Übertragen → 🌐 Fern-Einrichtung: Gerätecode anzeigen. Den QR-Code mit dem Handy scannen – dann ist der Code hier schon eingetragen.
  4. Den Code an die Person schicken, die den Fernseher einrichtet.
3. Einrichtung hier senden
  1. Unten den Gerätecode eintragen.
  2. Xtream: Server-Adresse, Benutzername und Passwort vom Anbieter eintragen.
    M3U: den Playlist-Link eintragen.
    Sicherung: eine PintoTV-Sicherungsdatei (.json) hochladen – ersetzt alles auf dem Fernseher.
  3. Optional bei Länder antippen, welche Länder angezeigt werden sollen (gilt für TV, Filme und Serien). Nichts ausgewählt = alles.
  4. An den Fernseher senden tippen.
4. Am Fernseher übernehmen
  1. PintoTV auf dem Fernseher öffnen (oder neu starten). Ist der Playlists-Bildschirm offen, kommt die Einrichtung nach spätestens 15 Sekunden.
  2. Es erscheint „🌐 Fern-Einrichtung empfangen“ → Hinzufügen bzw. Übernehmen.
  3. Die Sender werden geladen – fertig. Die Daten werden danach hier gelöscht.
  4. Nichts angekommen? Am Fernseher ⇄ Übertragen → Gerätecode anzeigen → Jetzt abrufen drücken und prüfen, ob der Code stimmt.
Alternative: direkt aus der eigenen PintoTV-App senden
  1. Auf deinem Fernseher: Playlists → ⇄ Übertragen → 📤 Meine Einrichtung an Gerätecode senden.
  2. Code des anderen Geräts eingeben und wählen: Alles wie bei mir oder Auswählen (Playlists, Länder, Favoritenlisten).
  3. Dein Verlauf und deine Wiedergabe-Positionen werden nie mitgeschickt.

Einrichtung senden

Was soll geschickt werden?

Länder (optional)

Nur diese Länder werden auf dem Fernseher angezeigt – für TV, Filme und Serien. Nichts ausgewählt = alles.

Eine PintoTV-Sicherung (.json) mit allen Playlists, Favoriten und Einstellungen. Sie ersetzt die Einrichtung auf dem Fernseher.

Der Fernseher holt sich die Einrichtung beim nächsten Start von PintoTV oder sofort, wenn der Playlists-Bildschirm offen ist. Gespeicherte Daten werden nach dem Abruf gelöscht.

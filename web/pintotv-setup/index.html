PintoTV

Einen Fernseher aus der Ferne einrichten. Den Gerätecode zeigt PintoTV auf dem Fernseher an (Playlists-Bildschirm, oben).

Was soll geschickt werden?

Eine PintoTV-Sicherung (.json) mit allen Playlists, Favoriten und Einstellungen. Sie ersetzt die Einrichtung auf dem Fernseher.

Der Fernseher holt sich die Einrichtung beim nächsten Start von PintoTV oder sofort, wenn der Playlists-Bildschirm offen ist. Gespeicherte Daten werden nach dem Abruf gelöscht.
